IOSDecryptHub rootless

iOS 运行时安全分析工具 · v1.23.6

功能

  • 🔐 加解密 Hook（CommonCrypto / OpenSSL EVP）
  • 📁 文件 I/O 监控
  • 🌐 网络请求捕获
  • 🔑 Keychain 访问追踪
  • 📦 动态库加载监控
  • 🖥️ 内嵌 Web 面板（端口 8088）
  • 🤖 MCP 服务（AI Agent 远程分析）

使用

安装后在 设置 → IOSDecryptHub 中选择要注入的 App，重启目标 App 即可生效。Web 面板自动监听 0.0.0.0:8088。
