            01 — 能力全景
            
一次注入，六条监控与分析主线

            

              拦截的是 CommonCrypto、Security.framework、OpenSSL EVP 三套系统库，以及沙盒文件与动态库加载；
              再叠加进程内砸壳与 Capstone 反汇编。同名接口在 macOS 与 iOS 上通用。
            

          

          

        

      


      
      

        

          

            02 — 实时捕获流
            
注入进目标进程，事件即刻流出

            

              下面是一段模拟的捕获流：App 自己调用加密 API，每条调用都被解析成结构化事件。
              真实面板里，点任意一条即可展开 Key / IV / 明文 / 密文的 Hex、HexDump 与调用栈。
            

          

          

            

            

          

        

      


      
      

        

          

            03 — Web 面板
            
浏览器即控制台：多 tab 左右分栏

            

              dylib 加载后自动在 8088 起一个零依赖 HTTP 服务。加解密 / 文件 / 系统 / 符号 / Dump 五个 tab，
              共享同一套 master-detail。这是可交互的复刻——切 tab、点条目试试。
            

          

          

          

            
            
            
          

        

      


      
      

        

          

            04 — 算法覆盖
            
从 MD5 到 ChaCha20-Poly1305，一次性与流式都收

            

              摘要、HMAC、对称、非对称、KDF 全线覆盖；流式 Init / Update / Final 会把分片喂入的数据拼回完整明文。
              目标若链接 libcrypto，OpenSSL EVP 对称也一并接管。
            

          

          

        

      


      
      

        

          

            05 — 砸壳 / 脱壳
            
把内核已解密的内存，写回一份干净镜像

            

              FairPlay 加密的 __TEXT 在运行时已被内核解密进内存。按需触发——不点按钮就不跑，零额外开销——
              把已解密的页写回磁盘，并将 cryptid 置 0。产出可直接喂给 IDA / Ghidra，或重打包成可重签 IPA。
            

          

          

          

        

      


      
      

        

          

            06 — MCP · Capstone
            
给 AI 一个进程内的反汇编与交叉引用后端

            

              注入的 dylib 内置一个 MCP (Model Context Protocol) 服务器，复用 8088 端口。
              AI 客户端通过 JSON-RPC 调用 Capstone 反汇编、镜像枚举与四件套 xref。选一个工具看它做什么。

            07 — fail-loud
            
    失效就让它可见，绝不静默兜底

              悬浮窗红字、面板红色横幅、控制台 [IOSDecryptHub/ERR] 三处同时可见，但不中止宿主 App。
