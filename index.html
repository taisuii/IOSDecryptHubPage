IOSDecryptHub
看见运行时的真相

设备安装运行时插件，电脑安装 idh。连接同一可信局域网，即可发现 App 并开始分析。

iOS 14.0+ · rootless / roothide 添加插件源
源 https://ios.decrypthub.com/
macOS / Linux · Python 3.10+ 安装 idh
$ pip install ios-decrypt-hub

HTTP / MCP 服务不设认证，仅限授权测试与可信局域网；请勿将 8088 端口暴露到公网。

向下滚动
01 — 实时面板

插件里的运行时控制台，直接在这里操作

界面与插件内置页面保持一致。切换页签、筛选与搜索测试 IPA 产生的日志，点任意记录查看 Key、IV、输入输出、HexDump 与调用栈。

02 — 能力全景

同一条运行时链路，六种观察视角

拦截的是 CommonCrypto、Security.framework、OpenSSL EVP 三套系统库，以及沙盒文件与动态库加载； 再叠加进程内砸壳与 Capstone 反汇编。同名接口在 macOS 与 iOS 上通用。

03 — 算法覆盖

从 MD5 到 ChaCha20-Poly1305，一次性与流式都收

摘要、HMAC、对称、非对称、KDF 全线覆盖；流式 Init / Update / Final 会把分片喂入的数据拼回完整明文。 目标若链接 libcrypto，OpenSSL EVP 对称也一并接管。

04 — 砸壳 / 脱壳

把内核已解密的内存，写回一份干净镜像

FairPlay 加密的 __TEXT 在运行时已被内核解密进内存。按需触发——不点按钮就不跑，零额外开销—— 把已解密的页写回磁盘，并将 cryptid 置 0。产出可直接喂给 IDA / Ghidra，或重打包成可重签 IPA。

05 — MCP · 36 tools

从运行时取证到反汇编，全部工具都在这里

注入的 dylib 内置一个 MCP (Model Context Protocol) 服务器，复用 8088 端口。 36 个工具覆盖 Capstone 分析、内存与符号、运行时事件、沙盒文件、砸壳、捕获控制和配置。选一个工具查看调用方式。
