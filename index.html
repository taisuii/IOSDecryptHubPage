01 — 安装与连接

设备装插件，电脑装 idh

越狱设备通过 Sileo / Zebra 安装运行时插件；电脑通过 PyPI 安装命令行工具。 两端处于同一可信局域网后，idh 会自动发现已注入的 App。

macOS / Linux · Python 3.10+

安装 idh 命令行

用 pipx 独立安装，获得设备发现、面板打开和 MCP stdio 网关。

$ pipx install ios-decrypt-hub
  1. 确认设备idh devices
  2. 打开面板idh open <target_id>
  3. 连接 AI Agentidh mcp
查看 PyPI 也可使用 python3 -m pip install ios-decrypt-hub
iOS 14+ · rootless

安装越狱插件

支持 Dopamine、palera1n 等 rootless 环境，依赖由包管理器自动解析。

源 https://ios.decrypthub.com/
  1. 添加软件源在 Sileo / Zebra 中添加上方地址
  2. 安装插件com.iosdecrypthub
  3. 选择目标 App设置 → IOSDecryptHub，启用后重启 App
在 Sileo 中添加 ElleKit 与 PreferenceLoader 会作为硬依赖安装。

IOSDecryptHub 的 HTTP / MCP 服务不设认证，仅用于同一可信局域网内的授权安全测试；请勿将 8088 端口暴露到公网。

02 — 实时面板

插件里的运行时控制台，直接在这里操作

界面与插件内置页面保持一致。切换页签、筛选与搜索测试 IPA 产生的日志，点任意记录查看 Key、IV、输入输出、HexDump 与调用栈。

03 — 能力全景

同一条运行时链路，六种观察视角

拦截的是 CommonCrypto、Security.framework、OpenSSL EVP 三套系统库，以及沙盒文件与动态库加载； 再叠加进程内砸壳与 Capstone 反汇编。同名接口在 macOS 与 iOS 上通用。

04 — 算法覆盖

从 MD5 到 ChaCha20-Poly1305，一次性与流式都收

摘要、HMAC、对称、非对称、KDF 全线覆盖；流式 Init / Update / Final 会把分片喂入的数据拼回完整明文。 目标若链接 libcrypto，OpenSSL EVP 对称也一并接管。

05 — 砸壳 / 脱壳

把内核已解密的内存，写回一份干净镜像

FairPlay 加密的 __TEXT 在运行时已被内核解密进内存。按需触发——不点按钮就不跑，零额外开销—— 把已解密的页写回磁盘，并将 cryptid 置 0。产出可直接喂给 IDA / Ghidra，或重打包成可重签 IPA。
